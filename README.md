# Đức Trọng — Portfolio

A responsive frontend portfolio created for the Portfolio assignment.

## Files

- `index.html` — page structure and content
- `styles.css` — responsive visual design
- `app.js` — navigation, project filters, modal details, form UI
- `assets/profile.jpg` — **add your own real profile photo here**

## Run locally

Open `index.html` directly in a browser, or use the VS Code Live Server extension.

## Before submitting

1. Replace `assets/profile.jpg` with your own photo.
2. Replace `your-email@example.com` with your real email.
3. Replace the GitHub link with your GitHub profile.
4. Review the project descriptions and change anything that does not accurately describe your work.
5. Create a public GitHub repository and push the files.

## Git commands

```bash
git init
git remote add origin https://github.com/YOUR_USERNAME/Portfolio.git
git add .
git commit -m "Initial portfolio upload"
git branch -M main
git push -u origin main
```

## GitHub Pages

Repository → Settings → Pages → Source: `main` → Folder: `/root` → Save.

The assignment guide requires each student's portfolio to be customized and unique, so this template should be edited before submission.
